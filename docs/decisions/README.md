# Decisions

Legal, tax and hard-rule questions where opinions conflicted, decided with the `legal-decision` skill (`.claude/skills/legal-decision/`). Each folder holds the question, the research prompt, the answers, the citation check and the decision record. A decision is reopened only by one of the triggers it lists.
